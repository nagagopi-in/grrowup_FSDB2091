This repository contains my solutions for the FSDB2091 Web Technologies training, Weeks 1 to 6. Each week features a series of tasks designed to build foundational skills in HTML, CSS, and web design.

### Task 1: Personal Website Homepage
- **Description:** Create a personal website homepage showcasing skills and interests.
- **Requirements:** 
  - Header with name and navigation
  - Main content with introduction and skills list
  - Profile picture

### Task 2: Product Catalog Page
- **Description:** Design a product catalog page for an online store with categories and product details.
- **Requirements:** 
  - Header with store name and category list
  - Product sections with images, titles, descriptions, and links

### Task 3: Blog Post Page
- **Description:** Develop a blog post page with title, author name, publication date, and content.
- **Requirements:** 
  - Header with post details
  - Main content with paragraphs
  - Custom favicon

### Task 4: Facebook Profile Header
- **Description:** Create a profile header similar to Facebook with profile picture, cover photo, and user information.
- **Requirements:** 
  - Layout for profile and cover photos
  - Display user information clearly and aesthetically

### Task 5: Instagram Logo Representation
- **Description:** Design a representation of the Instagram logo using HTML and CSS.
- **Requirements:** 
  - Colorful gradient background
  - Camera outline and lens elements

### Task 6: Amazon-Inspired Product Listing Page
- **Description:** Design a product listing page inspired by Amazon with product cards and filtering options.
- **Requirements:** 
  - Multiple product cards with images, descriptions, and prices
  - Filtering by category and price range using HTML and CSS

---

> **Note:** Each task demonstrates the application of web design techniques and the use of modern HTML/CSS practices. For code and live previews, please check the respective folders/files in this repository.
